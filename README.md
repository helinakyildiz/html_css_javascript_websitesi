# 🏗️ İnşaat Firması Web Sitesi

Bu proje, modern bir inşaat firması için tasarlanmış, yalnızca **HTML**, **CSS** ve **JavaScript** kullanılarak geliştirilmiş statik bir web sitesidir.

## 🔍 Genel Özellikler

- 🖥️ Ana sayfa, çalışanlar, projeler ve iletişim bölümleri
- 🌐 Mobil uyumlu ve responsive tasarım
- 🎯 Kullanıcı dostu arayüz
- 📸 Proje galeri bölümü 
- 📩 İletişim formu 

## 🚀 Kurulum ve Kullanım

1. Proje klasörünü bilgisayarına indir.
2. `web.html` dosyasını bir tarayıcıda aç.
3. Tüm dosyalar HTML, CSS ve JS ile statik olarak çalıştığı için ekstra kurulum gerekmez.
